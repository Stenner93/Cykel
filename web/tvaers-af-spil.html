Hvorfor vi droppede den interne model

To sæsoners data pegede samme vej begge gange. Det er beslutningsgrundlaget for at gå væk fra "modellen vælger ryttere" og over til rene kilde-sammenligninger (se kilde-shootoutet) og facilitator-værktøjer fremadrettet.

Konklusion: den interne model (exp/ML-laget) er ikke en pålidelig beslutningskilde — den er nu droppet som reference i den løbende analyse. Fremadrettet sammenlignes de eksterne kilder (Feltet, Simon/TheFantasyTool, VeloScore, odds) direkte mod hinanden og mod virkeligheden, uden en model-baseline i midten. Infrastruktur-huller fundet undervejs

Skal rettes FØR Klassiker Manager i foråret 2027 — nogle af disse kan ikke genskabes bagefter.

1 build_analytics.py kørte hardcoded mod TdF hele Vuelta-sæsonen

Har ALDRIG læst Vuelta-data, selvom daily.yml kaldte den dagligt. Konsekvens: data/cache/stage_snapshots.json (etape-niveau pris/ejerskab-historik) findes kun for TdF — den tabte Vuelta-historik kan ikke genskabes. Fix: generalisér med samme --race-mønster som de øvrige scripts, og bekræft den rent faktisk kører mod det aktive løb.

✓ eval_managers.py — rettet denne session

Byggede spiller-ID→navn af den delte, løbende opdaterede data/cache/holdet_players.json i stedet for løbets egen gemte reference — kollapsede stille til nul-værdier for ethvert løb der ikke er det aktuelt scrapede. Rettet til at bruge reference/players.json fra løbets eget gemte snapshot.

2 Holdet's leaderboard-endpoint er ikke ensartet på tværs af spil

games/628/leaderboard (Vueltaspillet) gav ikke gyldig JSON. Vueltaens manager-sammenligning dækker derfor kun dig og Kasper, ikke top-10. Fix: find og hardcod det rigtige endpoint tidligt i Klassiker Manager, eller accepter manuel --team-ids-indtastning som fast rutine.

Handling frem mod Klassiker Manager

  • Drop den interne model som beslutningskilde — bekræftet to løb i træk. Byg i stedet værktøjer der sammenligner eksterne kilder og fremmer dine egne overvejelser.
  • Ret infrastrukturhullerne før løbet starter — vi får kun ét forsøg pr. sæson på etape-niveau-historikken.
  • Kør snapshot_holdet_teams.py --race <løb> proaktivt undervejs, ikke kun som brandslukning lige inden spillet lukker.
